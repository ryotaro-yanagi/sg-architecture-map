# SGM Prototype 01 — iPhone Safari 実機確認

公開URLの末尾を `?ui=a`、`?ui=b` にして、両方式を同じ端末・同じ条件で確認する。

## 共通

- [ ] 初回表示で地図、7件のピン、地図クレジットが見える
- [ ] 拡大・縮小・パンが指1本／2本で自然に操作できる
- [ ] 3件のピンを連続選択しても、意図しない中心・ズームのリセットがない
- [ ] 建築名と設計者の検索ができ、0件表示も崩れない
- [ ] 詳細に設計、竣工年または「未確認」、用途、所在地、出典が表示される
- [ ] Google Maps、Google検索、画像検索からSafariの戻る操作で地図状態に復帰できる
- [ ] 写真未掲載、暫定座標、公開アクセス未確認の表示が意図どおり見える
- [ ] 縦向き／横向き、表示拡大100%／125%、ライト／ダーク設定で文字や操作が欠けない
- [ ] VoiceOverで検索、現在地、A/B切替、詳細開閉の名前が読み上げられる

## UI A

- [ ] 浮遊プレビューが地図操作とピンを過度に隠さない
- [ ] 「詳しく見る」から詳細パネルへ進み、「地図へ戻る」で同じ地図状態に戻る

## UI B

- [ ] 下部シートのハンドルと「詳しく見る」の両方で展開できる
- [ ] 展開後の内容を末尾の出典までスクロールでき、たたむ操作ができる

## 現在地

- [ ] 許可時：現在地マーカーが表示され、地図が現在地へ移動する
- [ ] 拒否時：案内メッセージが出た後も検索・ピン選択・地図操作を継続できる
- [ ] Safari設定で位置情報を再許可した場合も再試行できる
